# Bapple

## 브랜치 설명
**main**: 
- **목적**: 프로덕션 배포용 안정 버전
- **설명**: 기능이 완성되어 검증을 마친 후, `Dev` 브랜치에서 Merge됩니다.

**Dev**:
- **목적**: 개발 및 기능 구현
